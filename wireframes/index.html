최종 디자인 (HNBCF_메인 대시보드_20260515) 반영 내역

  • 상신자 (Case 1): 4카드 (미상신 / 결재 진행중 / 결재 완료 + 반려 병합 / 이체 완료 + 오류 듀얼) + 빨간 오류 알림 + FX TRADING 배너
  • 결재자 (Case 2): 3카드 (미결재 / 결재 완료 + 반려 병합 / 이체 완료 + 오류 듀얼) + 노란 리스크 알림 + DC 퇴직연금 배너
  • 사이드바에 수기계좌 메뉴 추가 (내역관리/리포트 ↔ 대금지급 사이)
  • 03 팝업/모달: 01/02는 결재자 컨텍스트, 03/04는 상신자 컨텍스트로 분리

피그마 변환 시 참고

  • html.to.design 플러그인 사용 시 각 HTML 파일을 개별 프레임으로 import 가능합니다.
  • 모든 시각 요소는 1px dashed border + 그레이스케일 fill로 표현되어 와이어프레임 의도를 명확히 합니다.
  • 레이아웃은 flexbox/grid 기반으로 작성되어 Figma의 Auto Layout으로 변환됩니다.
  • 알림과 배너의 변형 클래스 (.error/.warning, .fx/.dc)는 미세한 색조 차이로 구분되어 피그마에서도 컴포넌트 변형으로 인식하기 쉽습니다.
  • 공통 스타일은 base.css 파일에 정의되어 있으니, 디자인 시스템으로 활용하실 수 있습니다.
